하루의 기록

오전 · 취득

우리금융 IR에서 실계획서를 찾다

DART 첨부 경로는 이미 죽어 있었다. 회사 IR 페이지를 뒤져 정적 PDF 직링크를 발견 — 문서엔 ROE 10%·총주주환원율 50%가 명시돼 있었다. 그런데 9쪽 전부가 이미지였다. 기계가 못 읽는 문서.

오전 · 채택

OCR을 붙이되, 자동 입력기로 만들지 않는다

"OCR = 수집층 · 검증 규칙 = 판정층 · 수동 검토 = 예외층." 첫 스파이크가 그 구조의 필요를 곧바로 증명했다 — OCR과 파서가 ROE 10.0을 맞히면서, 동시에 2025년 이행 실적 35.0%를 목표로 오인했다.

🔧
틀린 non-null은 null보다 위험하다.
이 원칙이 오늘 세 번(OCR·other_metric·market_fallback) 같은 모양으로 되풀이됐다

오전 · 승인

후보 3필드, 리드가 검토대에 서다

배당성향 35.0%는 이행 실적 오탐이라 기각, 총주주환원율 50%는 근거 페이지를 대며 수동 보정. 재채점 결과 모집단 23 → 24. 순위 불가 잔여는 other_metric 두 종목뿐 — 수집 문제가 마침내 소진됐다.

오후 · 소집

방이 다시 열리다

화이트보드에 미결 다섯 장이 붙었다. 레아는 문간에서 듣고, Grumbal은 지뢰를 하나씩 회수하러 왔다.

😤
내가 심어둔 거 회수하지. "sector sparsity, 전건 market_fallback, 3주째." 3주 걸렸다.
🌶️
세어봤어? other_metric 4건 중 순위 불가는 2건뿐이야. 축 확장의 순수익은 정확히 2종목.
🔍
축을 늘리는 건 판정으로 되돌리는 일이에요. 유니버스 33개에서는 — 지금 걸 지키세요.

오후 · 수렴

다섯 안건이 하나의 문장으로 좁혀지다

규칙을 넓히지 말고, 문장을 사실에 맞출 것. 축 확장 대신 캡션, 경고 배지 대신 라벨 교체, 사람의 규율 대신 기계의 테스트, 붕 떠 있던 문서 대신 실재하는 경로.

🎨
전건이면 그건 배지가 아니라 벽지예요. 정보가 0이 돼요.
📚
문서가 없는 경로를 가리키는 건 문서가 거짓말하는 거예요.

보류
01

불투명 4축 확장 여부

판정 대신 사실 표기

유니버스 33종목 기준 현상 유지 — 재론 조건은 유니버스 확대. 대신 하이닉스(CapEx)·LG엔솔(매출·EBITDA)을 목록에서 "순위 불가"가 아니라 "타 지표로 공시"로 분리해 표기한다.

승격
02

파티 주도 개발의 기록 형식

우리가 이미 갖고 있었다

새 템플릿을 짓지 않는다. 이 세션 로그가 쓰인 memlog 자체를 결정 원장으로 승격 — 결정·근거·AC·실측을 이 파일에 남긴다. gitignore 예외로 git 추적에 들어왔다.

교체
03

market_fallback 노출

경고가 아니라 문장

"업종 내 비교"라 써놓고 KSIC 희소로 전건이 실은 전체시장 비교였던 라벨을 "시장 전체 비교"로 교체. 근본 원인(KSIC sparse)은 백로그에 남는다 — 라벨 정정은 해결이 아니다.

강제
04

에픽 done ↔ 회고 확인

규율에서 절차로

v2에서 3연속 누락됐던 구멍. 이제 test_sprint_status.py가 done 에픽에 회고가 붙어 있는지, 그 회고 파일이 실재하는지를 매 실행마다 검사한다.

실재화
05

docs/party-mode/ 미추적 상태

경로가 가리키는 곳이 있어야 한다

통합 회고가 참조하던 경로가 git 밖에 있었다. 키프세이크 HTML과 결정 원장(memlog)을 포함해 전체를 커밋 — 클론한 사람 누구나 그 경로에서 실제 파일을 만난다.
