# Story 1.11: 축=0 구간 전수 재판독 — 검사된 적 없는 35건

Status: done

## Story

As a 애널리스트,
I want 본문에 수치로 적힌 우리 4축 목표가 빠짐없이 파싱되는 것,
so that 채점 종목 수와 발표 숫자가 실제 공시와 어긋나지 않는다.

## Acceptance Criteria (epics.md 1.11)

1. **축=0 구간 210건 전수** 재판독(35건만이 아니라 전부).
2. 라벨-값 사이 **개행**과 **값 앞에 오는 목표 표지**를 인식하도록 파서 확장.
3. 실측 5건이 각각 **죽일 수 있는 회귀 테스트**로 고정.
4. 1.10 일괄리뷰가 막은 오탐 3종이 재발하지 않음을 테스트로 단언.
5. **재공시 참조의 직교 승격**(파티 비준 2026-08-06): `choose_plan`이 라벨이 아니라 `body_reference_date`를 따른다 — 파싱 성공으로 라벨이 바뀌어도 원공시 이동 유지.
6. 채점 종목 수·점수 변동 before/after 보고(**변동 0이어도 보고**).

## ⚠️ 착수 전에 읽어라 — 이 스토리가 위험한 이유

**이 스토리가 요구하는 두 완화는 1.10에서 High 3건을 맞은 바로 그 방향이다.**

1.10 일괄리뷰(2026-07-13, GPT)의 제목이 *"정규식이 남의 숫자를 훔침"*이었다. 그때 막은 것:

| 오탐 | 차단 방법 |
|---|---|
| `ROE(2024년 5%) 배당성향 30%` → 30을 ROE로 | 괄호 안 %·경쟁 지표 금지 (tempered gap) |
| 화살표가 다른 지표의 체인을 훔침 | 좌·중 gap에 경쟁 라벨 금지 |
| `주주환원율 50% ROE 목표 12%` → 50을 환원율 목표로 | `_TARGET_MARK` 룩어헤드에 경쟁 라벨 배제 |

**개행을 열고 표지 창을 넓히면 이 방어들이 동시에 약해진다.** 개행 너머는 대개 *다른 항목*이기 때문이다. 그래서 이 스토리의 본체는 "정규식 완화"가 아니라 **"완화하되 오탐 0을 유지하는 것"**이고, AC 4가 AC 2보다 중요하다.

> 이 프로젝트의 원칙(NFR2): **애매하면 null.** 틀린 non-null은 미파싱보다 나쁘다.
> 커버리지를 올리려다 틀린 값을 넣으면 SM-C1 위반이다.

## 근본 원인 — 실측으로 특정됨 (2026-08-06)

5건에 `parse_targets()`를 직접 돌렸고 **10개 정규식 중 하나도 발화하지 않았다.** 원인은 하나가 아니라 **네 가지**다.

### 원인 A — 라벨과 값이 다른 줄 (plan 98·99, 서울보증보험)

```python
'ROE \n- 중장기 목표 10% \n2. 기업가치 제고를 위한 실행방안'
```

`_plain_gap`의 `pre`/`tail`이 `[^0-9%\n(]`·`[^0-9%\n]`로 **개행을 금지**한다. 공시가 `③ ROE` 다음 줄에 `- 중장기 목표 10%`를 쓰는 불릿 서식이라 통째로 끊긴다.

> 개행 금지는 **의도된 방어**였다(다른 항목의 숫자를 훔치지 않기 위해). 제거가 아니라 **조건부 허용**이 필요하다.

### 원인 B — 목표 표지가 값 **앞**에 있다 (plan 317, 코웨이)

```python
'주주환원율 상향: 당기순이익(연결)의 40% \n3) 재무건전성과...'
```

gap은 통과한다(개행 없음, 괄호 1개 허용 범위). **`_TARGET_MARK`가 실패**한다 — 값 뒤 12자에 표지가 없고, 표지(`상향`)는 **값 앞**에 있다. 현재 `_TARGET_MARK`는 값 뒤만 본다.

### 원인 C — 표지 창 12자를 3자 초과 (plan 215, 한솔케미칼)

```python
'주주환원율 20~50% \n- 2026년 주주환원 확대 적극 검토'
```

`_RETURN_RANGE_RE`의 범위 매칭은 되지만 `_TARGET_MARK`가 실패한다. 표지(`확대`)가 **15자째**이고 창은 `{0,12}`이며, 게다가 `[^\n]`이라 **개행을 넘지 못한다.**

> ⚠️ **이 문서에는 실적도 같이 있다**: `2) 주주환원 초과 달성 - 주주환원율 57%`는 **2025년 이행 실적**이다. 목표(20~50%)와 실적(57%)이 같은 문서에 나란히 있다. 표지 조건을 느슨하게 풀면 **57%를 목표로 삼는다.** `_TARGET_MARK`가 존재하는 이유가 정확히 이것이다(5-1 실샘플: 13건 중 5건이 과거 실적이었다).

### 원인 D — 역순, 값이 라벨 앞 (plan 72, 현대지에프홀딩스)

```python
'별도 당기순이익 기준 80% 이상 주주환원율 지향'
```

`_PAYOUT_REVERSE_RE`(배당성향 역순)는 있으나 **`_RETURN_LABEL`에는 역순 규칙이 없다.**

> 🚫 **이 건은 파싱해도 채택하지 마라.** `별도 당기순이익 기준` 80%는 회사가 **자기 정의를 명시**한 경우다. 2026-08-05에 환원율 축 소각 기준 재론을 기각한 근거가 *"기업마다 총주주환원율 정의가 다르다"*였다. 다른 정의로 채점하면 그때 기각한 것을 되살리는 셈이다.
> **처리**: 파싱 규칙은 만들되 이 건은 **조건부 백로그 P1-9의 트리거 후보 1건으로 계상**하고 값은 넣지 않는다. 판단이 서지 않으면 리드에게 물어라.
